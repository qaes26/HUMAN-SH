# تشريح حب شادية ❤️
> **إعداد: قيس الجازي**

لوحة تشريحية تفاعلية ثلاثية الأبعاد مبنية باستخدام **Three.js** ومخصصة بالكامل للهواتف الذكية.
يتضمن المشروع مجسماً تشريحياً مفصلاً (الهيكل العظمي، العضلات، الأعضاء الحيوية، والأوعية الدموية) يتفاعل باللمس لتقديم رسائل غزلية وعاطفية خاصة بشادية.

---

## 📱 المميزات
- **مخصص للهواتف الذكية بنسبة 100%**: واجهة مستخدم عصرية وفاخرة تدعم اللمس المتعدد، إيماءات السحب للـ Bottom Sheet، وتصميم أنيق للهواتف.
- **مجسم ثلاثي الأبعاد تفاعلي**: تحكم كامل (تدوير، تكبير/تصغير، واختيار الأعضاء بالنقر المباشر مع وميض تفاعلي).
- **غزل شاعري مخصص لكل عضو**: كل جزء تشريحي (القلب، الدماغ، العيون، العمود الفقري، الرئتان...) يحمل غزلاً خاصاً لشادية.
- **رسالة خاصة**: نافذة تضم رسالة حب من أعماق القلب من قيس الجازي إلى ملهمة الروح شادية.
